## Packages

<CardGrid stagger>
  <Card title="Headless Core" icon="rocket">
    `@agent-dev-lab/core` — A framework for developing AI agents and workflows built on top of

  </Card>
  <Card title="Web Inspection UI" icon="laptop">
    `@agent-dev-lab/web` — An optional UI built on TanStack Start that triggers runs and consumes
    telemetry using the `@agent-dev-lab/core` API.
  </Card>
  <Card title="CLI" icon="npm">
    `@agent-dev-lab/cli` — The `adl` command: scaffold a project with `adl init`, run agents and
    workflows from the terminal, and launch the inspection UI with `adl dashboard`.
  </Card>
</CardGrid>
